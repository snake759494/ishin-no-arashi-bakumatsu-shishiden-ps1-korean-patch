# 유신의 폭풍 막말지사전 (PS1) 비공식 한글패치

PS1 일본판 **維新の嵐 幕末志士伝 (유신의 폭풍 막말지사전, SLPM-86144)** 비공식 한국어 패치입니다. 이 저장소에는 제작 도구와 기술 문서만 있고, 패치 파일(xdelta)은 [Releases](../../releases)에서 받을 수 있습니다. 게임 원본·일본어 원문·번역 대본은 포함하지 않습니다.

## 적용 방법
1. 아래 해시와 일치하는 **원본 `.bin`/`.cue`** (Redump 형식, 트랙 4개: 데이터 1 + 오디오 3)를 준비합니다. (CHD·PBP·ECM 등으로 변환한 이미지에는 적용할 수 없습니다.)
   - PowerShell: `Get-FileHash -Algorithm MD5 -LiteralPath '.\Ishin no Arashi - Bakumatsu Shishiden (Japan) (Track 1).bin'`
2. xdeltaUI 같은 도구로 원본 **트랙 1** `.bin` 에 `Ishin_no_Arashi_Bakumatsu_Shishiden_KO_v1.1.xdelta` 를 적용합니다. (Patch = xdelta, Source File = 원본 트랙 1 BIN, Output File = 새 파일명)
   - 명령줄: `xdelta3 -d -s "Ishin no Arashi - Bakumatsu Shishiden (Japan) (Track 1).bin" Ishin_no_Arashi_Bakumatsu_Shishiden_KO_v1.1.xdelta "Ishin no Arashi - Bakumatsu Shishiden (Japan) [KR] (Track 1).bin"`
3. 원본 `.cue` 를 복사해 이름을 바꾸고, 첫 번째 `FILE "..."` 줄(트랙 1)만 새 `.bin` 파일명으로 고칩니다. 트랙 2~4(오디오)는 원본 파일을 그대로 씁니다.
4. 만들어진 `.cue` 를 DuckStation 등 PS1 에뮬레이터나 ODE 장치에서 실행합니다.

## 주의
- v1.0에서 게임 저장 시 "메모리 카드 확인 중" 창에서 멈추던 문제가 v1.1에서 고쳐졌습니다. v1.0 사용자는 v1.1 xdelta를 **원본** BIN에 다시 적용하세요.
- 원본에서 만든 **상태저장(세이브 스테이트)** 은 불러오지 마세요. 실행 파일과 글꼴 배치가 달라 글자가 깨지거나 멈춥니다. 메모리 카드 세이브는 그대로 쓸 수 있습니다.
- xdelta는 압축하지 않은 형식(`-0`)입니다(약 1.5MB).

## 한글화 내용
- 실행 파일·오버레이 14개·이벤트 대사 6개 파일의 문자열 21,409개 직접 번역(지역 사투리는 말투를 살려 번역)
- 게임 글꼴(12×12)의 한자 영역에 한글 2,352자(완성형 2,350자 + 번역에 쓰인 글자) 추가, 본문은 갈무리11 원래 크기
- 이름 입력 화면의 가나 표를 한글 자모 표로 교체
- 메시지 줄바꿈을 게임의 줄 길이 판정(공백 8px)에 맞춰 다시 계산
- 표·목록 칸 맞춤 — 인물 목록, 지역 목록, 카드 목록, 관광(온천·명물) 배치, 탭 이름 등이 칸을 넘지 않도록 서식 문자열과 좌표를 조정
- 화투 미니게임의 한자 숫자를 한글 숫자로
- 그림 글자 — 타이틀 로고(「유신의 폭풍 / 막말지사전」)와 타이틀 버튼, 시나리오 선택 카드 이름판, 상태창(연호·행동력·소지금·연월일), 명령 버튼 59종, 성향 태그(좌막·존왕·양이·개국·주전·온건), 사상 도표 29장, 지역 지도 이름표 51종, 축제 등롱 14종, 검술 시합 글자, 연타 미니게임 현판(「연타일념」), 설득 화면 사상 도표
- 글꼴: 본문·작은 그림 글자 갈무리11·갈무리9, 로고·버튼·상태창 서울한강체, 타이틀 부제 나눔스퀘어 네오

## 그대로 둔 것
- 배경 그림 속 간판·현판(도장 현판, 가게 간판, 「誠」 깃발 등) — 게임 세계 안의 소품으로 보고 원래대로 둠
- 음성, 영상, KOEI 로고, 메모리 카드 관리 화면에 보이는 세이브 제목

## 검증 범위
DuckStation에서 타이틀·시나리오 선택, 본편 대사, 정보 메뉴의 주인공 목적·세력 정보·인물 정보(전 탭)·다른 인물 정보·소지품(카드·소개장·관광·도구)·주변 정보(지구·다른 마을 목록), 명령 버튼, 사상 도표, 축제 등롱을 확인했습니다. 연타 현판과 설득 도표는 디스크에 들어간 이미지를 대조해 확인했고, 게임 안에서 해당 장면을 띄워 보지는 못했습니다. 실행 파일과 오버레이 문자열은 전수 검사했고, 전체 플레이 검증은 하지 않았습니다. 문제를 발견하면 Issues에 알려 주세요.
